Aula 1

Apresentação

  • Apresentacao do docente e Estudantes
  • Apresentacao do plano analitico na cadeira de programacao web

Linguagens a serem lecionadas

  • Html
  • Css
  • JS
  • php

Nesta primeira aula, conhecemo-nos uns aos outros e o docente apresentou o plano analítico.Falámos sobre as metas do semestre e as ferramentas que vamos usar, como o VSCode e o XAMPP.Foi um momento que nos desperto a curiosidade sobre a cadeira de progrmacao Web.

Aula 2

HTML

  • Introduncao ao Html
  • Historia da Internet
  • Introduncao a tags num html

Aprendemos sobre o início da Internet e como o HTML surgiu para estruturar páginas. Descobrimos que as tags são como blocos que formam um site.Cada tag tem uma função específica e ajuda a organizar o conteúdo.Fizemos pequenos exemplos e criámos as nossas primeiras páginas.Foi o primeiro passo para nos nessa cadeira de programação Web

Aula 3

Listas ordenadas e não ordenadas

  • Listas ordenadas <ol>
  • Listas não ordenadas <ul>
  • Itens de lista <li>

Nesta aula aprendemos a organizar conteúdos com listas. Usámos listas ordenadas para itens com sequência e não ordenadas para tópicos livres.Fizemos exercícios de menus e listas de compras em HTML.Vimos que são muito úteis para menus navegação e estruturas simples.Foi uma aula prática e divertida onde percebemos o poder da organização no HTML.

Aula 4

Formatação de texto

  • Tags para formatar texto (b, i, u)
  • Cabeçalhos (h1 a h6)
  • Parágrafos e quebras de linha (p, br)

Aprendemos como dar ênfase ao texto usando tags como b,i e u. Vimos que uma boa formatação torna a página mais agradável e fácil de ler. Testámos diferentes combinações para destacar partes importantes. Também aprendemos a diferença entre tags de bloco e inline. Foi uma aula cheia de estilo e prática com o HTML puro.

Aula 5

Links e imagens

  • Criação de links "a"
  • Inserção de imagens img;
  • Atributos importantes (href, src, alt)

Nesta aula aprendemos a colocar links e imagens nas páginas. Descobrimos como navegar entre páginas e adicionar fotos locais e online. Falámos sobre o uso ético das imagens e direitos de autor. Criámos páginas com menus e galerias simples.

Aula 6

Prática: Criação de um site de receitas

  • Estrutura completa do site
  • Uso de listas, links e imagens
  • Apresentação visual e semântica do conteúdo

Aplicámos tudo o que aprendemos para criar um site de receitas. Estruturámos as páginas com listas, imagens e links entre elas. Trabalhámos em grupo para partilhar ideias e melhorar o design. Cada grupo criou uma receita moçambicana tradicional. Foi uma experiência prática que nos mostrou o poder da programação web.

Aula 7

Tabelas

  • Criação de tabelas <table>
  • Cabeçalhos <thead>, linhas <tr>, células <td>
  • Mesclagem de células (colspan, rowspan)

Aprendemos a criar tabelas para organizar informações de forma clara. Usámos as tags table, "tr e td" para estruturar os dados. Fizemos exemplos com notas, produtos e horários. Vimos também como combinar células e adicionar bordas. Foi uma aula de muita prática e paciência, mas com bons resultados.

Aula 8

Formulário

  • Criação de formulários <form>
  • Inputs: texto, senha, radio, checkbox
  • Botões de envio e reset

Aprendemos a criar formulários para recolher dados dos utilizadores. Usámos campos de texto, botões e seletores de opções. Vimos como o formulário é essencial em qualquer site moderno. Fizemos exemplos de cadastro e login simples. Foi uma aula que nos preparou para o lado interativo da web.

Aula 9

Introdução ao CSS

  • Seletores e propriedades
  • Alteração de cores, fontes e bordas
  • Classes e IDs

Entrámos no mundo do CSS e aprendemos a dar estilo às páginas. Mudámos cores, fontes e espaçamentos com código simples. Vimos como o CSS separa o design da estrutura do HTML. Experimentámos diferentes estilos e combinações criativas.

Aula 10

Estilização de texto e centralização de div, textos e imagens

  • Centralização com text-align e margin auto
  • Estilização de fontes e cores
  • Alinhamento de imagens e conteúdo

Nesta aula aprimorámos o uso do CSS para posicionar e alinhar elementos. Centralizámos textos, imagens e caixas usando propriedades modernas. Aprendemos a importância do equilíbrio visual numa página. Também vimos como usar margens e alinhamento automático. Foi uma aula visualmente bonita e cheia de experimentos.

Aula 11

Introdução ao JavaScript

  • Sintaxe básica
  • Manipulação de elementos HTML
  • Eventos e funções

Começámos a aprender JavaScript, a linguagem que dá vida às páginas. Fizemos os primeiros scripts para interagir com o utilizador. Entendemos a diferença entre HTML, CSS e JS. Criámos exemplos simples com alertas e manipulação de textos. Foi o início de uma nova fase mais dinâmica e poderosa da programação web.

  • Atualização dinâmica do conteúdo

esta aula aprendemos a usar o AJAX para criar páginas mais dinâmicas e rápidas. O professor explicou como as requisições assíncronas funcionam e como o navegador pode buscar informações de um servidor sem precisar recarregar a página toda.
